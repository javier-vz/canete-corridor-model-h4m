**Distribution gate:** The Supplementary PDF is *not* included in this public candidate.
Figure S3 uses plotted archaeological cell centres, and several internal editorial/author notes
are still present in the PDF. Before submitting and publishing the supplement, authors must:

1. decide with the archaeological project whether those positions may appear in a published map;
2. if not, remove/generalise the triangles and verify no alternative SVG/PDF layer exposes them;
3. resolve the author's validation notes in S4 and S5;
4. harmonise nomenclature “fixation field L” vs the current manuscript's “composite field L”;
5. regenerate the final PDF and verify its concordance with the manuscript's S1–S6 references.

The main PDF also contains the labelled cells in **Figures 5 and 6**. Their labels have been corrected
to “Site-labelled cells (n=84)”, which does **not** remove the location disclosure.

Do not treat a removed CSV column as sufficient privacy protection when other materials retain
cell-centre locations. This is a release decision, not a request for new H4m simulations.
